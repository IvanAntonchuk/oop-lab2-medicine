# Medicine

Виконав: Антончук Іван ІПС-31

Лабораторна робота №2 з ООП, варіант 4: «Лікарські препарати».

Java-додаток, який працює з XML-файлом з лікарськими препаратами:
валідація за XSD-схемою, розбір парсерами SAX, DOM та StAX, сортування
колекції через `Comparator` і XSL-перетворення в XML зі зміненою структурою
(групування препаратів за групою).

Проєкт у розробці, повний опис буде додано наприкінці.
